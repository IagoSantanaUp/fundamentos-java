# Estrutura Sequencial

Classes que praticam a forma mais básica de algoritmo: instruções executadas **em ordem**, de cima para baixo, sem desvios nem repetições.

O ponto de atenção aqui é a **ordem das instruções** — cada passo pode depender do anterior, e trocar a sequência pode quebrar o resultado (ex: usar uma variável antes de inicializá-la).

## O que colocar aqui

Exercícios de entrada → processamento → saída sem nenhuma decisão ou laço: cálculos diretos, conversões, montagem de resultado a partir de dados de entrada.
