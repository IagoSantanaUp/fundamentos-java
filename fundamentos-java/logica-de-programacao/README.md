# Lógica de Programação

As três estruturas fundamentais de controle de fluxo, segundo o Teorema de Böhm-Jacopini: **sequência**, **seleção** e **iteração**. Qualquer algoritmo pode ser expresso combinando apenas essas três.

- [`estrutura-sequencial/`](./estrutura-sequencial) — instruções executadas em ordem, uma após a outra.
- [`estrutura-condicional/`](./estrutura-condicional) — decisões: `if`, `else`, `switch`, ternário.
- [`estrutura-repetitiva/`](./estrutura-repetitiva) — repetições: `for`, `while`, `do-while`.
