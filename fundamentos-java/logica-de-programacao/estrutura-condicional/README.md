# Estrutura Condicional

Classes que praticam decisões: `if`, `else`, `else if`, `switch` e o operador ternário — a capacidade do algoritmo de seguir por caminhos diferentes conforme uma condição.

Ponto de atenção: a **ordem das condições** num `if-else-if` importa (a primeira verdadeira "ganha"), e o `switch` clássico exige `break` para não sofrer *fall-through*.

## O que colocar aqui

Validações, classificações (faixas de nota, categorias, status), regras de negócio simples que dependem de uma ou mais condições.
