# Fundamentos-java

Repositório onde documento minha prática de estudo dos fundamentos de Java — classes escritas por mim conforme avanço nos estudos, organizadas por tema.

Este não é um repositório de teoria (a teoria eu estudo e documento à parte); aqui ficam os **exercícios e implementações práticas** de cada conceito, como prova de que sei aplicar o que estudei.

## Estrutura

## Como uso este repositório

Cada pasta recebe as classes `.java` que escrevo enquanto estudo aquele tópico — não são cópias de tutorial, são minhas próprias tentativas de resolver problemas e aplicar o conceito, incluindo os erros que cometo no caminho. Cada arquivo tem um nome que indica o que ele demonstra (ex: `CalculadoraSalario.java`, `ValidacaoDeSenha.java`), e comentários explicando o raciocínio nos pontos que considero importantes.
