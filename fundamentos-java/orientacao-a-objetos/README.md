# Orientação a Objetos

Classes que praticam os conceitos fundamentais de POO: classes, objetos, atributos, métodos, construtores, e os quatro pilares (Encapsulamento, Herança, Polimorfismo, Abstração).

Ponto de atenção: atributos sempre `private`, acesso controlado por métodos (getters/setters com validação quando fizer sentido); herança só para relações genuínas de "é um".

## O que colocar aqui

Modelagens de domínios reais (conta bancária, produto, funcionário, veículo) exercitando cada pilar — de preferência com uma classe de teste (`main`) mostrando o comportamento em ação.
